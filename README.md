# 中国城市分级地图 · 2026

[在线页面](https://citiescn.hiww.top/) · [源码仓库](https://github.com/RichardHuang0001/china-city-atlas) · [数据来源与口径](docs/sources.md)

以第一财经·新一线城市研究所知城数据库 2026 版（`city_charm.2026`）六档城市分层为基准，结合中国行政区划与矢量地图，提供全国及省级交互地图、线级筛选与城市名录检索，完整覆盖内地 **333 个地级行政区**（293 座地级市及 40 个自治州、地区、盟）与 **4 座直辖市**，合计与数据库 **337 席**一致。

## 产品功能

- **六档数字徽标**：一线至五线采用 6 种互不重复的徽章轮廓与内嵌数字（`1` / `1+` / `2` / `3` / `4` / `5`），并配合温和的体积阶梯与低饱和暖色，无需反复对照图例即可识别线级。
- **渐进式缩放披露**：
  - 通过地图右上角「＋／−／全览」按钮（或聚焦地图后使用 `+` / `-` / `0` 键）按固定档位缩放；放大后可在桌面端拖拽或在手机端单指拖动平移。
  - 全国视图默认保持画面疏朗，随放大级别逐级展开更多线级城市名；点击 3 次「＋」进入深度视野后，自动铺开虚线地市界线以区分省界。
- **全国 / 省级 / 南海附图联动**：
  - 点击地图上的省份或顶部下拉框可进入省级视图，查看省内地级区划边界，并可通过缩放按钮旁的「返回全国」快速退回全局。
  - 海南视图与页面左下角卡片支持切换独立的南海诸岛附图，选中「三沙」时自动跳转。
- **独立筛选与城市名录**：
  - 地图线级勾选仅控制地图标点与名称；名录区域支持按线级、排序方式（榜单图序、省份、线级、城市名）与关键词搜索独立查阅，点击任意城市即可定位并高亮对应省份。
  - 名录采用独立内嵌滚动框，与整页浏览明确区分，4 座直辖市单列在「直辖市参考」中。
- **零依赖离线可用**：全部采用原生 HTML、CSS、JavaScript 与 SVG 构建，无需联网地图瓦片或外部框架。如本地已包含 `site/assets/map-data.js`，直接打开 `site/index.html` 即可使用。
