# 备选增量功能策划案：自定义权重重算、多维城市画像与十年时间线（未实施草案）

> **文档状态**：备选策划草案（暂存目录，尚未进入开发排期）。  
> **适用基线**：`中国城市分级地图 · 2026`（原生 HTML / CSS / JS / SVG 零依赖静态架构，线上版见 [site/index.html](../site/index.html)）。

---

## 一、产品定位与必须守住的约束

本策划旨在充分利用本地已归档的 **2026 年 337 城多维得分**、**2016–2026 年 11 年历史面板** 与 **112 项客观统计指标**（存放于 [research/datayicai-mcp/](../research/datayicai-mcp/README.md)），为地图增加「按自己关心的维度重算排名」和「单城多维画像」能力。

遵循本仓库既有设计原则（见 [AGENTS.md](../AGENTS.md)），后续无论做到哪一期，必须严守 5 条红线：

1. **零侵入默认体验**：首次打开页面时，必须默认选中「知城 2026 官方归档版（默认）」，地图视觉、徽标轮廓、渐进缩放、标签避让和移动端默认勾选项（`一线～三线`）与现网完全一致。
2. **数据诚实、双口径隔离**：自定义权重算出的排名和分级属于**用户视角衍生重算结果**，UI 上必须明确显示「自定义权重重算」提示标签与相对默认版的名次变化，绝不将其冒充第一财经官方榜单。
3. **纯前端离线可用**：保持原生 ES/IIFE 脚本与静态资源结构，不引入前端框架、后端 API、CDN 图表库或运行时密钥，确保本地 `file://` 与静态托管子路径均可用。
4. **控制包体与首屏性能**：地图底图（`map-data.js`）约 3.6 MB，核心数据（`data.js`）仅约 29 KB。新增多维分值包应独立拆分为按需或轻量化静态脚本，压缩控制在 **50–90 KB** 以内。
5. **不碰“脱敏原值”陷阱**：知城 2026 数据中 26 项商业合作方底层原值按来源方要求未展示，且 16 项二级维度原始量纲不统一。所有权重计算**只使用 337 城 100% 数值全覆盖的层**，并对二级维度在构建阶段做好归一化。

## 三、分期功能设计（克制、可用、低耦合）

### Phase 1（P0）：视角预设 + 五大一级维度权重调节器

**核心价值**：把静态地图变成“可换尺子”的城市观测台，且数学上 100% 稳健（五大维度均在 `0–100` 统一尺度）。

1. **交互入口位置（不动地图主构图）**
   - 在地图顶部筛选栏下方（或「城市名录」面板上方）放一条紧凑的折叠工具栏：**`视角：知城 2026 默认 ▾` + `调权重` 按钮**。
   - **默认收起滑块**，保持当前首屏视觉克制感；点击预设或「调权重」后才展开 5 个滑块与「重置」按钮。

2. **精选 5 套预设视角（经本地 2026 真实数据实测验证）**
   - **知城 2026 默认**：直接使用 `data.js` 原档分组与线内序（`0.20 / 0.19 / 0.22 / 0.21 / 0.18`）。
   - **硬核产业与人才**（商业 `0.10` / 枢纽 `0.15` / 活跃度 `0.10` / 新经济 `0.35` / 未来可塑性 `0.30`）：
     - 实测变化：杭州（#6→#5）、苏州（#8→#7）、天津（#14→#12）、合肥（#17→#16）名次上升；二线门槛上**潍坊**升入二线、**乌鲁木齐**退至三线。
   - **消费与烟火气**（商业 `0.32` / 枢纽 `0.10` / 活跃度 `0.38` / 新经济 `0.15` / 未来可塑性 `0.05`）：
     - 实测变化：上海（#2→#1）反超北京、青岛（#19→#17）升至第 17；二线门槛上**洛阳**重返二线、**保定**退至三线。
   - **交通枢纽与区域辐射**（商业 `0.20` / 枢纽 `0.40` / 活跃度 `0.10` / 新经济 `0.15` / 未来可塑性 `0.15`）：
     - 实测变化：武汉（#9→#8）、郑州（#13→#12）上升，**昆明**（#20→#19）跃入新一线前 19 席，**兰州**升入二线。
   - **均衡五边形**：五项各 `0.20`。

3. **滑块设计与前端实时重算逻辑**
   - 5 个 `<input type="range" min="0" max="100" step="5">`，右侧实时显示归一化百分比（如 `35%`），用户无需手动凑满 100%。
   - **加权与分档映射**：
     - 对全部 337 城计算加权分 $S_i = \sum_{k=1}^{5} w_k \cdot d_{i,k}$（当全为 `0` 时自动退回默认）。
     - 按降序排列得到衍生总榜名次 `1..337`，并按官方固定席位配额 `[4, 15, 30, 70, 90, 128]` 映射出新的 `tier`（0–5）与 `tierRank`（1–N）。
   - **UI 反馈**：
     - 非默认模式下，页面副标旁或工具条显示温和提示：`衍生重算口径 · 仅按当前权重重排（非官方分级）`。
     - 名录表格的「线内序」旁增加轻量变化角标（如 `↑2` / `↓1` 或 `升二线`），一眼看出哪座城市受益于当前权重。
     - 地图徽标与标签布局自动复用现有 `render()` 流程：仅更新内存工作副本 `activeCities` 的 `tier` 与 `rank`，不改动 `map-labels.js` 避让算法。

---

### Phase 2（P1）：单城多维详情升级 + 十年线级轨迹

**核心价值**：把现有底部仅一行文字的 `#city-detail` 升级为信息密度恰当的「单城小档案」（保持不遮挡地图画布）。

1. **城市详情卡内容（点击地图或名录任意城市后展开）**
   - **基础与衍生定位**：显示「官方 2026 线级/总榜名次」与（若开启自定义权重）「当前权重名次与变动」。
   - **2026 五维能力条**：用 5 条纯 CSS/SVG 横向进度条展示该城在「商业 / 枢纽 / 活跃度 / 新经济 / 未来可塑性」的得分（0–100）。
   - **2016–2026 十年线级胶囊**：一行紧凑排列 11 年（`'16`–`'26`）对应的线级小色块与文字提示（如合肥：`二 二 二 二 新 二 新 新 新 新 新`），让用户直观感受城市十年跃迁。
   - **客观家底参考（带统计年份标注）**：展示最新 GDP（亿元）、GDP 增速（%）、常住人口（万人）、全体/城镇人均可支配收入（元）、高铁站数（个）；缺值字段诚实显示 `—（暂无公开数据）`。

### Phase 3（P2，可选进阶）：16 项二级维度调权与双城对照

1. **16 项二级维度展开调节**
   - 在权重面板提供「展开 16 项细分指标」折叠区，覆盖大品牌青睐、商业核心、商业配套、交通联系、城际流动、产业协同、区域中心、消费/休闲/夜间活跃度、企业引领力、新消费、产业链生态、创新氛围、人才吸引力、城市规模。
   - **量纲统一**：在构建脚本中对 16 项二级维度统一做 Min-Max 归一化到 `0–100` 写入数据包（同时保留原始得分字段供详情展示），彻底解决 PCA 原始区间差异导致的权重失真问题。
2. **双城横向对照**
   - 在单城详情卡右上角提供「加入对比」按钮（最多选 2 座城市），弹窗或下方展开极简双栏对比（5 大一级分 + 16 项二级分差值 + 宏观统计对比）。

## 四、静态数据包与工程改动清单（实施阶段参考）

若决定启动 Phase 1，预计只需以下克制且可维护的工程改动：

1. **数据包拆分（推荐独立文件 `site/assets/metrics-2026.js`）**：
   - 保持 `site/assets/data.js` 轻量且向后兼容（仍可直接单独运行）。
   - 新增脚本 `scripts/build_metrics.py` 从 `research/datayicai-mcp/` 提取并生成 `site/assets/metrics-2026.js`：
     - `dims5`：`{ code: [d1, d2, d3, d4, d5] }`（保留 2 位小数，337 城约 12 KB）
     - `dims16Norm`（P1/P2 再加）：Min-Max `0–100` 后的 16 项值（约 32 KB）
     - `historyTiers`（P1 再加）：337 城 2016–2026 线级索引串（如 `"11111111111"`，仅约 5 KB！）
     - `stats`（P1 再加）：精选 6–8 项高覆盖客观指标 `[val, year]`（约 18 KB）
   - 同步更新 `hiww-web/apps/citiescn/build.mjs` 的 `assets` 复制清单及 `site/index.html` 的 `<script defer>` 引入顺序。
2. **校验脚本扩展（`scripts/verify_data.py`）**：
   - 校验 `metrics-2026.js` 与 `data.js` 的 337 个六位行政区划代码完全一一对应；
   - 校验 `dims5` / `dims16Norm` 无 `NaN` / `null` 且数值均落在 `[0, 100]` 区间；
   - 验证使用默认权重重算时，与官方 `data.js` 名次高度一致。
3. **测试与防回归要求**：
   - 移动端（360 / 390 px）必须保证权重面板默认折叠，展开后滑块与按钮触控高度不小于 `36–40 px`，且不挤压地图可视区；
   - 切换权重触发 `render()` 后，桌面端 337 标记、标签避让单调性、省级视图拖拽退出及名录独立滚动均不得退化。
