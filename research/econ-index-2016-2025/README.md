# 城市十年经济发展指数（2016–2025）学术建模说明

本目录保存由 `build_econ_index.py` 生成的 337 城年度「经济发展指数（Economic Development Index, EDI，0–100）」与方法论校验结果（仅用于本地研究与双轴组合图原型，暂不修改正式站点）。

## 1. 五维学术指标与非对称动能设计

| 维度 | 指标定义 | 数据处理与学术依据 | 客观 CRITIC 权重 |
| --- | --- | --- | ---: |
| 经济体量底座 | $\ln(\text{2025可比价真实 GDP})$ | 五经普口径倒推真实增量 + UNDP HDI 对数去偏态 | **15.6%** |
| 产出效率质效 | $\ln(\text{2025可比价人均真实 GDP})$ | 消除单纯靠人口堆砌体量的偏差，端年缺失仅作相邻常住人口承接 | **16.5%** |
| 公共财力造血 | $\ln(\text{一般公共预算收入})$ | 衡量地方真实税基与财政造血能力（阿里 24–25 缺失按 OECD 可用项重加权） | **14.0%** |
| 绝对增长与收缩灵敏度 | 实际增速 $\tilde{g}$ | Kahneman & Tversky (1992) 前景理论 $\lambda = 2.25$ 负增长非对称加重 + `[2%, 98%]` 对称缩尾 | **28.4%** |
| 相对全国与减速动量 | 超额/跑输与二阶减速组合 | 低于当年全国基准（$\lambda = 2.25$）与相对前两年均值减速（$2.0\times$ 下行响应）+ `[2%, 98%]` 缩尾 | **25.7%** |

### 关键细节说明
- **为什么兼顾“低于当年全国水平”与“增速明显放缓”？**
  仅仅放大负增长（`g < 0`），只能识别少数极端收缩年份，看不出像 **沈阳 2025（2.0% vs 全国 5.1%）**、**广州 2024（2.0% vs 全国 5.1%）**、**东莞 2022–2023（0.6%/2.6% vs 全国 3.0%/5.4%）** 这类明显掉速或落后全国大盘的阶段。将超额增速先剥离当年全国宏观波动，再与前两年超额均值作差，既不会在 2022 疫后基数回落年误伤健康城市，又能精准刻画每座城市自身的加速与失速拐点。
- **为什么用 CRITIC（Diakoulaki et al., 1995）客观赋权？**
  体量、人均产出与财政收入之间存在显著正相关（$r = 0.59 \sim 0.97$），CRITIC 根据标准差与 $(1-r_{jk})$ 冲突信息量自动扣减存量冗余，并配合学界常用的 `[2%, 98%]` 缩尾避免极个别极值年份压扁常规城市的起伏，自然得出「`46.0%` 长期实力底盘 + `54.0%` 增长与波动动能」的均衡结构，使每条曲线充分呈现凹凸起伏。
