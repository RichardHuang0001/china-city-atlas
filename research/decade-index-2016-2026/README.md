# 城市 2016–2026 排名变化轨迹说明

本目录保存由 `build_decade_index.py` 生成的 337 城 **2016–2026（11 个连续年度版次）** 全国总榜位次轨迹，专用于前端 **`2016-2026`** 柱状图组件。

## 口径与展示原则

1. **全口径一致、零缺失**：直接采用第一财经·新一线城市研究所知城数据库 `city_charm` **2016–2026 共 11 年**全量 337 城总榜名次（`#1`–`#337`）与六档线级，最后一个柱子即 **2026 年版（`'26`）**数据。
2. **动态局部排名纵轴**：放弃全局 `0–100` 固定水位缩放，改为每座城各自围绕其历史排名区间 `[bestRank, worstRank]` 自适应展开纵轴（左侧纵轴明确标注 `#最高名次 / #中段 / #最低名次`）。排位越靠前（数字越小）柱子越高，最大化放大每座城十年间的升降幅度。
3. **直观升降双向编码**：
   - 以 **2016 年起步名次虚线**为参照线；
   - 名次高于 2016 的年份以亮珊瑚红帽突出「排名攀升」；
   - 名次低于 2016 的年份以灰紫柱体 + 斜纹缺口直观呈现「排名回落 / 下坡趋势」。
